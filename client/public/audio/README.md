# Vice Heist music assets

The spatial playlist expects these browser-compatible MP3 files in this directory:

1. `kleiner-finger.mp3` — Bohren & der Club of Gore, converted from the supplied M4A.
2. `rose-bianche.mp3` — supplied MP3.

The game starts the playlist from the splash-screen user gesture. In gameplay, the music is spatialized around the VIP lounge and becomes quieter and more muffled as the player moves away.

The binary files are intentionally not represented by placeholders. Add the actual audio files here; the playlist skips unavailable files and stops if neither track exists.
